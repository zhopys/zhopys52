АННОТАЦИЯ
Курсовой проект на тему: Программное средство для учета личных финансов, состоит из программного средства, пояснительной записки и графической части.
Программное средство предназначено для автоматизации финансового учёта, контроля и анализа денежных потоков малого бизнеса. Система обеспечивает централизованный учёт операций, автоматическую категоризацию транзакций, формирование ключевых финансовых отчетов, прогнозирование кассовых разрывов и управление напоминаниями.
Программное средство разработано с использованием языка программирования C# и технологического стека .NET 8, включая ASP.NET Core (Web API), фреймворк Blazor и базу данных SQLite.
Пояснительная записка выполнена на 99 листах, содержит четыре раздела и одно приложение.
Графическая часть выполнена на двух листах, включает диаграмму вариантов использования и диаграмму деятельности.

ВВЕДЕНИЕ
Актуальность эффективного учёта финансов для малого бизнеса в современных экономических условиях сложно переоценить. Высокая конкуренция, рост издержек, нестабильность рынка и постоянные изменения в законодательстве требуют от предпринимателей чёткого понимания финансового состояния своего бизнеса. Регулярный и грамотный учёт доходов и расходов позволяет своевременно выявлять проблемные зоны, оптимизировать затраты, контролировать денежные потоки и принимать обоснованные управленческие решения.
В настоящее время современные программные решения являются одним из ключевых инструментов повышения финансовой дисциплины и эффективности малого бизнеса. Они позволяют не только фиксировать операции, но и проводить глубокий анализ, формировать отчёты и прогнозировать развитие компании.
Целью выполнения курсового проекта является расширение и углубление знаний в области проектирования и разработки современных веб-приложений, изучение архитектуры ASP.NET Core, фреймворка Blazor и работы с базами данных.
Задачей курсового проекта является разработка платформы учёта расходов малого бизнеса «FINANCE CONTROL» — веб-системы, предназначенной для автоматизации финансового учёта и анализа в малом и микробизнесе.
Пояснительная записка содержит следующие разделы:
«Назначение и область применения» описывается назначение программы, краткая характеристика области применения программы. «Технические характеристики» – рассматриваются следующие вопросы: формирование требований к системе в целом; требования к функциям (раздел «Постановка задачи»); требования к организации данных в проекте, описание их организации, структуры, построение концептуальной и логической модели данных, способа кодирования (при необходимости) и предварительной подготовки (раздел «Описание организации данных»); обоснование выбора программного обеспечения, используемого для разработки программного средства (раздел «Описание программных средств»); проектирование программного средства. «Тестирование и анализ полученных результатов». Описывается проверка работы программы на различных тестах и приводится анализ ожидаемых и полученных результатов, выводы по результатам тестирования.

Описание программных средств
В данном проекте используется язык программирования C# и современный технологический стек .NET 8.
C# — это современный, объектно-ориентированный язык программирования, разработанный компанией Microsoft. Он отличается высокой производительностью, безопасностью типов, богатой стандартной библиотекой и удобством разработки.
Для реализации проекта выбраны следующие технологии:
ASP.NET Core (Web API) — мощный кроссплатформенный фреймворк для создания веб-приложений и API. Обеспечивает высокую производительность, масштабируемость и современные возможности безопасности.
Blazor — фреймворк для создания интерактивного веб-интерфейса на C# вместо JavaScript. Позволяет писать как клиентский, так и серверный код на одном языке.
SQLite — легковесная, быстрая, кроссплатформенная встраиваемая база данных, не требующая установки сервера. Идеально подходит для малого бизнеса.
C# широко используется для разработки современного программного обеспечения и является одним из самых популярных языков программирования в мире. Область его применения включает создание веб-приложений, десктопных программ, мобильных приложений, облачных сервисов, игр, корпоративных систем и высоконагруженных серверных решений.
C# отличается чистым синтаксисом, высокой безопасностью типов, богатой стандартной библиотекой и отличной поддержкой со стороны Microsoft. Язык активно развивается и входит в экосистему .NET.
Для реализации проекта используется ASP.NET Core — современный кроссплатформенный фреймворк для создания веб-приложений и API.
Ключевые особенности выбранного стека:
Высокая производительность и масштабируемость.
Кроссплатформенность (Windows, Linux, macOS).
Мощные возможности для работы с базами данных (Entity Framework Core).
ASP.NET Core применяется для разработки современных веб-приложений, корпоративных систем, микросервисов и SaaS-решений..
Главное преимущество .NET 8 — это сочетание высокой производительности, удобства разработки и кроссплатформенности. В отличие от классического подхода, где клиентская и серверная части пишутся на разных языках, ASP.NET Core + Blazor позволяют использовать C# на всём стеке — от сервера до браузера. Это значительно ускоряет разработку, упрощает поддержку и снижает вероятность ошибок.

Главная форма служит связующим звеном между всеми формами. На главной форме пользователь может управлять записями, перейти на формы аналитики и настроек. Записи просматриваются с помощью таблиц расходов и доходов. Добавление записей происходит с помощью формы добавления записи на которую можно перейти нажав кнопку «Добавить запись», рис. 4.3. Изменение записей происходит с помощью формы изменения записи на которую можно перейти нажав кнопку «Изменить запись», рис. 4.3. Удалить запись можно нажав кнопку «Удалить запись». Также записи можно фильтровать нажав по таблице правой кнопкой мыши и выбрать пункт меню «Настроить фильтр», который откроет форму настроек фильтров, рис. 4.4. Чтобы применить фильтр нужно отметить нужные фильтры и нажать кнопку «Применить фильтр». Активные фильтры будут отмечены иконкой на форме настроек фильтра, а также таблица к которой применен фильтр. Все настройки фильтра можно сбросить нажав кнопку «Сбросить фильтр». Также фильтр можно быстро отключать и включать нажимая по таблице записей и выбирая пункты меню «Применить фильтр» и «Снять фильтр», рис. 4.4.

Чтобы перейти с главной формы на форму настроек нужно нажать на «Шестерёнку». Форма настроек состоит из вкладок «Настройки» и «Категории», рис. 4.5. На вкладке «Настройки» можно поменять тему приложения выбрав ее из списка, сменить логин или пароль нажав по ним правой кнопкой мышки, а также выйти из аккаунта нажав кнопку «Выйти из аккаунта», которая вернёт пользователя на форму авторизации. На вкладке «Категории» можно выбрать категорию из списка категорий, создать новую категории или удалить существующею. При удалении категории может оказаться что она используется в записях, тогда будет открыта форма удаления категории, где пользователю нужно выбрать другую категорию такого же типа, которая заменит удаленную категорию, рис. 4.6. Пользователь может изменять параметры выбранной категории такие как имя, цвет и тип.

Рис. 4.6. Форма удаления категории
На форму аналитики можно перейти нажав на кнопку главного меню «Аналитика». Форма аналитики состоит из вкладок «Статистика» и «Данные», рис, 4.7. На вкладке статистики можно выбрать период, за который будет отображена статистика. Статистику можно сохранить в файл Excel нажав кнопку «Сохранить». На вкладке данных пользователь может выбрать данные для экспорта и нажав кнопку «Экспорт» они будут сохранены в файл Excel. Также пользователь может импортировать свои записи в приложение нажав кнопку «Импорт» и выбрав нужный файл Excel. При импорте следует придерживаться структуры таблицы приведённой в таблице 4.1. Ячейки в столбике «Имя категории» можно красить в цвет этой категории, тогда у импортированных категорий будет свой цвет. Ячейкам в столбике «Тип категории» ставят значение 1 если операция это доход, и 0 если это расход. Если при импорте категория операции уже существует ей будет присвоена существующая категория, в противном случаи будет создана новая категория.

ЗАКЛЮЧЕНИЕ 
В ходе курсового проекта было разработано программное средство для введения личных финансов. В  приложении были реализованы функции управления операциями и категориями, экспорта и импорта данных, сбор статистики. 
В качестве выбранного языка программирования используется C++.  
В качестве выбранной среды разработки используется C++ Builder.  
Программное средство было протестировано методом «черного ящика» и включало 11 тестов. Тестирование прошло успешно. Дальнейшую модификацию системы вижу в добавлении совместного введения финансов, расширенние объема сбора статистики с применением графиков и диаграмм, улучшение функций формирования отчетов.
